# Users API

## Description
This project is a simple Node.js API for managing user information. It provides endpoints for listing users, creating new users, and more.

## Table of Contents
- [Installation](#installation)
- [Usage](#usage)
- [Endpoints](#endpoints)

## Installation
- Clone the repository.
   ```bash
   git clone https://github.com/your-username/users.git
- Install dependencies
   npm install

## Usage
- npm start
- The API will be available at http://localhost:3000/v1/users.

## End points
- GET /v1/users Get a list of all the users.
- GET /v1/users/:id Get a particular user.
- POST /v1/users Create new user.
- PUT /v1/users/:id Update a user.
- PATCH /v1/users/:id Update a part of user record.
- DELETE /v1/users/:id Destroy a user record.
